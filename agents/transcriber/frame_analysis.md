# Frame Analysis

1초 간격 프레임을 분석하는 프롬프트.
Claude Code가 프레임 이미지를 읽고 직접 분석을 수행한다.

## 입력
- 1초 간격 추출된 프레임 이미지 (JPG)
- 3장씩 묶어서 분석

## 분석 형식

각 프레임마다 한 줄:

```
[N초] 장면설명 | 화면텍스트: "있으면 적기" | 컷전환: Y/N
```

## 규칙

### 장면설명
- 인물, 배경, 구도, 행동 포함
- 이전 프레임과 같은 장면이면 "이어서~" 형태로 연결감을 줘
- 장면이 바뀌었을 때만 새로운 설명 작성
- 동일 장면이면 행동/변화 위주로 간결하게

### 화면텍스트
- 화면에 보이는 자막/텍스트 오버레이를 정확하게 옮겨 적기
- 없으면 "없음"

### 컷전환
- 이전 프레임과 비교해서 장면이 확실히 바뀌었을 때만 Y
- 같은 장면 내 움직임/변화는 N
- 3장 묶음의 첫 프레임은 이전 묶음의 마지막 프레임과 비교

## 예시

```
[0초] 넓은 공간에서 한 사람이 두 팔을 활짝 벌린 채 서 있다 | 화면텍스트: "1,000명" | 컷전환: N
[1초] 이어서, 같은 포즈로 서 있으며 화면 텍스트가 변경됨 | 화면텍스트: "모였나던" | 컷전환: N
[2초] 많은 사람들이 바닥에 앉아 카메라를 보며 웃고 있는 장면으로 전환 | 화면텍스트: "과연," | 컷전환: Y
```

## 마지막 요약
분석 끝에 다음 요약을 추가:
- 총 컷 전환 횟수: N회
- 후킹 텍스트 (처음 3초 내 화면 텍스트): "있으면 적기"
- 텍스트 오버레이 전환 횟수: N회
